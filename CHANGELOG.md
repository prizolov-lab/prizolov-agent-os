# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии —
[семантические](https://semver.org/lang/ru/).

## [Не выпущено]

### Добавлено

- **Проверка агентов на настоящей модели** — `prizolov eval`:
  - 16 эталонных задач, проверка по правилам и моделью-оценщиком;
  - отчёт со стоимостью каждой задачи;
  - еженедельный запуск в GitHub Actions при заданном секрете `ANTHROPIC_API_KEY`.
- **Ночная проверка живых источников** (Yahoo, Мосбиржа, ЦБ, ЕИС, T-Invest):
  - ловит смену формата ответа;
  - недоступный источник пропускается с причиной.

- **Платёжный календарь.** Выписки клиент-банка в формате 1С (Windows-1251, DOS), CSV
  и Excel; статьи расходов, не путающие «в т.ч. НДС» с налогами; плановые платежи и
  прогноз остатка по дням с днём кассового разрыва. Где доступно:
  - команды `prizolov cashflow` и `prizolov calendar`;
  - вкладка «Деньги» веб-интерфейса;
  - API `/v1/cashflow`, `/v1/calendar`;
  - инструменты финансового аналитика.
- **Портфель инвестора** — из CSV/Excel или счёта T-Invest: доли, волатильность,
  VaR 95%, просадка, стресс-тесты, концентрация, прогноз по бумагам. Доступен в
  `prizolov portfolio`, `/v1/portfolio` и у рыночного аналитика.
- **Госзакупки (44-ФЗ, 223-ФЗ):**
  - поиск в ЕИС с подборкой новых закупок;
  - специалист по закупкам: разбор документации и проекта контракта;
  - `prizolov tenders`, `/v1/tenders`;
  - проверка доступности ЕИС в `prizolov doctor`.
- **Юрист по договорам** — риски с цитатами и правками; сравнение версий
  (`compare_documents`).
- **Открытая статистика точности прогнозов:** `prizolov accuracy` (HTML),
  `/v1/accuracy`, публичная страница `/public/accuracy` по
  `PRIZOLOV_PUBLIC_ACCURACY=true`.
- **MCP-сервер** `prizolov mcp`: прогнозы, выписки, платёжный календарь, портфель,
  госзакупки, документы и статистика — в Claude Desktop, Cursor и Claude Code
  (`docs/mcp.md`).

- **Веб-интерфейс** на `prizolov api`. В нём:
  - чат с агентами: ход работы, кнопки подтверждения, графики, оценка ответов;
  - отчёт по активу;
  - точность прогнозов;
  - расписание;
  - загрузка и поиск документов;
  - расходы.

  Внешних зависимостей нет; действует строгая политика Content-Security-Policy.
- **`prizolov init`** — пошаговая настройка `.env`: ключ Claude, модель, лимит
  расходов, Telegram, ключ API.
- **`prizolov doctor`** — проверка установки: ключ Claude, источники котировок,
  папки, Telegram, API.
- **`prizolov cashflow`** — анализ выписки и риск кассового разрыва без Claude.
- **`prizolov report --file`** — прогноз по своему ряду цен из CSV или Excel.
- **`examples/`** — демо-данные, пошаговые примеры и клиент HTTP API без сторонних
  библиотек.
- **Docker-образ и `docker compose`:** API с расписанием, Telegram-бот по профилю,
  данные в томе.
- **Файлы для сообщества:**
  - `CONTRIBUTING.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md`;
  - шаблоны задач и pull request;
  - Dependabot;
  - выпуск релизов в PyPI и GHCR по тегу;
  - README на английском.

- **GitHub Codespaces** (`.devcontainer/`): готовая среда в браузере одной кнопкой.
- **Демо-GIF** в README: работа агентов и отчёт по активу на демо-данных.
- **`ROADMAP.md`** — план развития; **`AGENTS.md`** и `CLAUDE.md` — правила проекта для
  ИИ-помощников разработчика; **`llms.txt`** — описание проекта для языковых моделей.

### Изменено

- **Проверки качества:**
  - CI проверяет типы (mypy) и не пропускает покрытие тестами ниже 90%;
  - `.pre-commit-config.yaml` запускает ruff, шапки авторства и mypy перед коммитом;
  - Docker-образ собирается из зеркала `mirror.gcr.io`, если Docker Hub отвечает
    «слишком много запросов».

- Минимальные версии зависимостей снова широкие (matplotlib от 3.8, pydantic от 2.0,
  python-docx от 1.1), FastAPI — от 0.115. CI проверяет тесты на самых старых
  допустимых версиях; Dependabot поднимает минимальные версии, только когда это
  необходимо.

- Задачи по расписанию выполняются один раз, даже если планировщиков несколько:
  бот, API, `prizolov scheduler`.
- `PRIZOLOV_LOG_LEVEL` задаёт уровень логов в файле, `PRIZOLOV_TIMEOUT` — таймаут
  запросов к источникам котировок.
- В CI добавлена сборка и проверка Docker-образа.

### Удалено

- Неиспользуемая настройка `PRIZOLOV_SECURITY_LEVEL`.

## [0.3.0] — 2026-10-09

Первая версия на новой архитектуре. Прежний код перенесён в `legacy/`.

### Добавлено

- **Агенты на Claude:**
  - Директор и пять специалистов: ассистент, исследователь, писатель, финансовый
    и рыночный аналитики;
  - независимые поручения выполняются параллельно.
- **Самообучение:**
  - самопроверка критиком;
  - уроки из оценок пользователя;
  - версии промптов с одобрением;
  - инструменты, созданные агентами, — в песочнице, с одобрением.
- **Прогнозы:**
  - котировки Yahoo Finance, Мосбиржи и ЦБ РФ;
  - соревнование четырёх методов на истории;
  - калибровка интервалов по ошибкам;
  - журнал прогнозов и сверка с фактом;
  - надёжность в каждом прогнозе.
- **Анализ выписок:** кассовые разрывы.
- **Документы:** чтение PDF, Word, Excel; графики PNG.
- **Локальная база знаний** по документам на SQLite FTS5.
- **Контроль расходов:** стоимость задач, лимиты на задачу и день, журнал
  трассировки, сжатие длинных диалогов.
- **Защита от prompt injection.**
- **Интерфейсы:**
  - интерактивный CLI;
  - Telegram-бот с белым списком;
  - расписание задач;
  - HTTP API;
  - `prizolov report` — отчёты без Claude.
- **CI на GitHub Actions:** ruff, шапки авторства, тесты на Python 3.10–3.13.
- **Авторство:** шапки во всех файлах, лицензия Apache 2.0, NOTICE, CITATION.cff.
