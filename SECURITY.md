# Безопасность

## Как сообщить об уязвимости

Не публикуйте уязвимость в открытом issue. Сообщить о ней можно двумя способами:

- через [приватный отчёт GitHub](https://github.com/prizolov-lab/prizolov-agent-os/security/advisories/new);
- письмом на **contact@prizolov.ru** с темой «Security: Prizolov Agent OS».

В сообщении укажите:

- версию (`prizolov --version`);
- шаги воспроизведения;
- чем грозит уязвимость.

Мы подтвердим получение в течение 3 рабочих дней и сообщим план исправления. Авторы
обоснованных отчётов будут упомянуты в списке изменений, если они не против.

## Поддерживаемые версии

Исправления безопасности выпускаются для последней версии из ветки `main`.

## Что особенно важно

- **Обход подтверждений.** Агент не должен записать файл или выполнить опасное
  действие без согласия человека.
- **Выход за рабочую папку.** Чтение или запись файлов вне `PRIZOLOV_WORKSPACE`.
- **Prompt injection.** Данные из интернета или документов не должны управлять
  агентом.
- **Песочница.** Инструменты, созданные агентами, не должны выходить из отдельного
  процесса.
- **Доступ без ключа или вне белого списка.** Это касается HTTP API и Telegram-бота.
- **Утечка секретов.** Ключ Claude, токен бота, ключи API.

## Рекомендации по эксплуатации

- Храните `.env` с правами 600 (`prizolov init` делает это сам) и не коммитьте его.
- Открывая HTTP API в сеть, ставьте впереди HTTPS-прокси и используйте длинные
  случайные ключи.
- Задайте лимиты расходов `PRIZOLOV_BUDGET_TASK_USD` и `PRIZOLOV_BUDGET_DAY_USD`.
- Перед одобрением (`/approve-tool`) читайте код инструментов, которые предлагают
  агенты.
